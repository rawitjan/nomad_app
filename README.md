# Nomad (Nomad Travel Kazakhstan) — Веб-платформа для путешествий и планирования маршрутов
 
**Nomad** — интерактивное SPA-приложение для исследования природных и исторических достопримечательностей Казахстана, расчета индивидуальных маршрутов и подбора авторских экспедиций.

Платформа решает типичные проблемы внутреннего туризма: отсутствие консолидированной информации о состоянии дорог и сезонности, сложности логистики между удаленными точками и необходимость вручную сопоставлять расстояния на карте.

---

## 🧭 Ключевые возможности

* **Агрегированный реестр локаций:** Каньоны Семиречья (Чарын, Темирлик), высокогорные озера (Кольсай, Каинды), марсианские урочища Мангистау (Бозжыра, Кызылкуп), гранитные массивы (Бектау-Ата, Баянаул, Бурабай) и историко-культурные комплексы.
* **Многофакторная фильтрация:** Поиск по регионам (Алматинская, Мангистауская, Восточно-Казахстанская, Туркестанская области и др.), категориям (горы, озера, каньоны, степи, памятники), рейтингу и уровню транспортной доступности.
* **Умный расчет логистики:** Встроенный геодезический модуль вычисляет расстояние между выбранными чекпоинтами по координатам широты и долготы, формируя ориентировочный тайминг переездов.
* **Оценка сложности подъезда:** Для каждой точки указаны требования к транспорту (асфальт / стандартный седан / подготовленный внедорожник 4WD), лучший сезон для посещения и доступность базовой инфраструктуры.
* **Быстрый доступ и сохранение:** Возможность сохранять понравившиеся точки в избранное с синхронизацией в локальном хранилище браузера.

## 🛠 Функциональные модули

### 1. Исследование локаций (`pages/Home.tsx`)

Стартовый экран платформы. Содержит:

* Поисковую строку с автокомплитом по названиям объектов и регионов.
* Карусель популярных направлений и сезонных рекомендаций.
* Чипы быстрых категорий (*Canyons, Lakes, Mountains, Deserts, Historical*).
* Сетку карточек `PlaceCard` с динамической сменой состояния избранного.

### 2. Интерактивная карта (`pages/WorldMap.tsx`)

Географическое представление базы данных объектов:

* Визуализация маркеров ключевых природных локаций на карте с привязкой к координатам.
* Превью объекта по клику на метку: фото, рейтинг, перепад высот и кнопка перехода к полному описанию.
* Фильтрация отображаемых точек прямо поверх слоя карты.

### 3. Детальная карточка места (`pages/PlaceDetails.tsx`)

Полный паспорт туристического объекта:

* Галерея фотографий в высоком разрешении.
* Точные GPS-координаты для навигаторов.
* Рекомендации по экипировке, наличию питьевой воды и связи (GSM/спутник).
* Интерактивная кнопка добавления локации в текущий путевой лист (`Add to Planner`).

### 4. Конструктор маршрутов (`pages/Planner.tsx`)

Рабочее пространство для самостоятельного путешественника:

* Формирование списка посещения из сохраненных объектов.
* Изменение порядка чекпоинтов с мгновенным пересчетом общего километража пути.
* Расчет приблизительного времени в пути с учетом коэффициента проходимости дорожного покрытия (трасса vs грейдер/степная колея).

### 5. Готовые туры и экспедиции (`pages/Tours.tsx`)

Каталог сформированных комплексных предложений:

* Джип-туры, трекинг-маршруты и фото-экспедиции.
* Расписание по дням, включенные опции (питание, трансфер, экосборы, ночлег в юртах/палатках).
* Уровень физической подготовки, необходимый для участия.

## 💻 Технологический стек

## 🗃 Архитектура состояния (State Management)

Управление данными в приложении организовано через централизованное хранилище `store/useStore.ts`.

Хранилище отвечает за следующие сущности:

1. **Избранное (`favorites`):** Хранит массив идентификаторов сохраненных мест. Позволяет быстро добавлять и убирать точки из закладок в один клик без перезагрузки экрана.
2. **Путевой лист (`plannedPlaces`):** Упорядоченный список объектов, выбранных для поездки. При изменении состава списка автоматически дергаются методы пересчета маршрута.
3. **Глобальные фильтры:** Текущий выбранный регион, категория и строка текстового поиска, применяемые к каталогу.

## 📐 Гео-калькуляция и логика расстояний

В модуле `utils/geo.ts` реализована формула гаверсинусов (Haversine Formula) для определения кратчайшего расстояния между двумя точками на сфере по их географическим координатам:

$$\Delta\sigma = 2 \arcsin \sqrt{\sin^2\left(\frac{\Delta\varphi}{2}\right) + \cos(\varphi_1) \cos(\varphi_2) \sin^2\left(\frac{\Delta\lambda}{2}\right)}$$

$$d = R \cdot \Delta\sigma$$

Где:

* $\varphi_1, \varphi_2$ — широта первой и второй точек в радианах;
* $\Delta\lambda$ — разность долгот;
* $R \approx 6371$ км — средний радиус Земли.

```typescript
// utils/geo.ts
export function calculateDistance(
  lat1: number, 
  lon1: number, 
  lat2: number, 
  lon2: number
): number {
  const toRad = (value: number) => (value * Math.PI) / 180;
  const R = 6371; // Радиус Земли в километрах

  const dLat = toRad(lat2 - lat1);
  const dLon = toRad(lon2 - lon1);

  const a =
    Math.sin(dLat / 2) * Math.sin(dLat / 2) +
    Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) *
    Math.sin(dLon / 2) * Math.sin(dLon / 2);

  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
  return Math.round(R * c);
}

```

Для расчета маршрута из нескольких точек массив локаций последовательно редуцируется с накоплением суммы отрезков между соседними чекпоинтами.

## ⚡ Установка и запуск

### Системные требования

* **Node.js:** версия `18.0.0` или выше.
* **npm** (v9+) или **pnpm / yarn**.

### Инструкция по развертыванию

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/rawitjan/nomad_app.git
cd nomad_app

```


2. **Установите зависимости:**
```bash
npm install

```


3. **Запустите локальный сервер разработки:**
```bash
npm run dev

```


Приложение станет доступно по локальному адресу (по умолчанию `http://localhost:5173`).
4. **Сборка проекта для продакшена:**
```bash
npm run build

```


Скомпилированные статические файлы будут сохранены в папку `dist/`.
5. **Предварительный просмотр сборки:**
```bash
npm run preview

```
